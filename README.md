# AETHERLUX — THE CAGE

Complete responsive website package for the Aetherlux fashion house.

## Brand
**AETHERLUX**  
*Fashioning Human Freedom*

## Current collection
**01 — THE CAGE**

The package includes:
- Hero homepage
- Aetherlux brand identity
- Human Freedom manifesto
- Six-chapter collection architecture
- Women's THE CAGE lookbook
- 10 generated fashion boards/images
- Fullscreen image viewing
- Mobile responsive layout
- Static deployment ready for GitHub Pages or Vercel

## Open locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `README.md`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
